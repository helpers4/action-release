# helpers4 release

Releases a TypeScript, Rust or mixed repository in one step: version from Conventional Commits,
changelog, release commit on `main`, tag, GitHub Release, and publication to npm, crates.io and
JSR.

> Work in progress: 0.2.0 is a rewrite. The documentation comes with the first release.
